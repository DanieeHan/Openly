# Openly

A small native macOS utility for managing default apps by file type.

管理 macOS 文件类型的默认打开应用。SwiftUI + AppKit 原生实现，无第三方依赖，无联网功能。

## 功能

- 查看当前默认应用，按文件类别筛选。
- 搜索文件类型、扩展名或当前应用。
- 从兼容应用菜单中修改默认应用，或自行选择本机 `.app`。
- 添加扩展名，或拖入文件识别实际系统类型。
- 保存最近 50 次操作，完整保留批次记录；支持逐项或整批撤销。
- 点击方框切换勾选；点击文件类型单选，按住 Shift 连选，按住 ⌘ 切换选择；通过“统一打开方式”批量更改。
- 批量显示进度，可停止剩余项；完整显示失败详情，支持重试失败及未处理项。
- 黑白灰界面，保留应用图标原色；支持系统深浅色外观。
- `⌘F` 搜索，`⌘R` 刷新。关闭窗口后退出。
- `⌘N` 添加类型。800 × 560 的紧凑窗口，使用直线分隔和几何层次。

## 0.2 轻量化

- 候选应用只在打开菜单时查询，关闭菜单后释放菜单项。
- 同一应用复用 64 × 64 像素原色缩略图；图标缓存限制为 32 项、512 KiB，名称缓存限制为 128 项。
- 默认应用没有变化时不重复发布列表更新；修改或撤销只验证受影响的文件类型。
- 避免启动时重复全量刷新；手动刷新始终立即生效。
- 使用体积优化、整模块优化和无用符号剥离；图标资源固定像素渲染，不依赖屏幕缩放比例。
- 不增加第三方依赖、后台服务、轮询或磁盘图标缓存。

本机测量结果及限制见 [PERFORMANCE.md](PERFORMANCE.md)。

## 0.2.1 修复

- 拖入符号链接时读取真实目标及目标扩展名；拒绝断链、文件夹和 Finder 替身，清理旧版错误的链接类型映射。
- 在系统设置前保存待确认记录，每项完成后更新；操作中关窗或退出会停止剩余项，等待当前系统操作完成后退出。
- 方框可以独立勾选和取消，批量工具栏保持固定位置。
- 批量结果保留完整失败列表，失败及未处理项可以重试；重试仍属于原来的批次。
- 历史按最近 50 次操作保留，单次批量超过 50 项也保留完整记录，支持整批撤销。

## 从源码构建

需要 macOS 13+ 和 Apple Command Line Tools（或包含命令行工具的 Xcode）。

```sh
git clone https://github.com/DanieeHan/Openly.git
cd Openly
zsh build.sh
open dist/Openly.app
```

产物为 `dist/Openly.app` 和 `dist/Openly.zip`。默认按当前 Mac 的处理器架构编译；可以设置 `OPENLY_ARCH=arm64` 或 `OPENLY_ARCH=x86_64` 进行交叉编译。Intel 构建尚未在实机验证。

日常使用请将最终版移入“应用程序”并替换旧版，只保留这一份已安装应用，避免启动台出现多个副本。

```sh
# 指定输出位置
zsh build.sh /path/to/Openly.app

# 运行逻辑测试，不改动本机默认应用
zsh test.sh
```

## 行为说明

修改会作用于系统内容类型，而非单个文件；属于同一类型的扩展名（例如 `.jpg` / `.jpeg`）会合并显示。应用菜单中显示系统类型标识。浏览器链接分流暂未包含。

需要用户同意时，由 macOS 自身显示确认提示。失败时显示错误，等待操作完成期间禁用修改。

批量菜单优先显示所选类型共同可用的应用，也可自行选择其他应用。Shift 的选择范围基于当前列表顺序；改变搜索或分类时会清除选择。批量完成后仅保留当前列表中失败或未处理的类型选中，结果中的重试入口保留原始未完成目标，不受之后的搜索筛选影响。

系统按类型逐项设置，可能逐项要求用户确认。普通失败不会回滚已完成项或阻止其他项；用户取消系统确认时停止后续操作。“停止剩余项”和退出请求都等待当前系统操作返回，无法关闭仍在等待处理的系统确认框。结果区分成功、无需更改、失败和未处理；全部成功时只显示底栏回执，失败或中止时展开结果。

每次写入系统前先保存待确认恢复记录，确认完成后立即更新；明确失败且关联未改变时删除该条未生效记录。默认应用已经是目标应用时不写入、不新增记录。意外中断后，待确认记录仍可供核查和撤销；这不是断电级事务保证。

撤销前会检查当前关联是否仍是该条记录设置的应用，避免覆盖后续修改。整批撤销也逐项检查，支持停止及重试未完成项。原始应用不存在或原本没有默认应用时无法自动撤销。记录只包含 Openly 发起的修改，不是所有系统设置的历史。

自定义类型与修改记录保存在本机用户偏好中。软件不联网、不收集遥测、不后台监控；预置列表不是系统所有文件类型的完整枚举。

## 源码结构

| 文件 | 内容 |
| --- | --- |
| `Sources/Model.swift` | 类型识别、系统接口、修改记录与撤销 |
| `Sources/Openly.swift` | 原生窗口、搜索、分类、应用菜单与历史记录 |
| `Tests/ModelTests.swift` | 使用替代服务验证修改与撤销，真实系统接口只读取 |
| `Tests/LifecycleTests.swift` | 验证操作中的退出会等待当前结果保存，不结束真实应用 |
| `Resources/` | App 信息和图标 |
| `Tools/MakeIcon.swift` | App 图标生成源码 |

测试覆盖类型合并、搜索筛选、图标缓存、Shift/⌘ 选择，以及符号链接、无效导入、旧偏好迁移、写入前记录、逐项持久化、停止/取消/重试、完整失败结果、整批撤销、外部修改保护、旧历史解码和完整大批次保留。所有系统写入由替代服务测试，真实系统接口只读取；原生界面及测量记录见 [PERFORMANCE.md](PERFORMANCE.md)。系统授权弹窗及不同 macOS 版本的真实写入行为仍需要独立环境验证。
